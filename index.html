Product · Python · LLM assistant

GoodLuck

A Windows and Mac desktop app that runs a job search end to end: it reads job boards, filters them by custom rules, scores each job against a CV sentence by sentence, tracks Gmail, and fills forms in Chrome.

The model never counts. The app does, and a guard drops any line with a figure the app did not compute.

Its LLM assistant (Groq, or Claude via the Anthropic API) picks one of 14 data lookups and answers from the app's own numbers. Drafts go to the model with no name, contact details or links, and Claude falls back to Groq when it fails.

Product · Python · .NET 10 · QuantConnect LEAN

Cat Studio

A Windows desktop app where you connect blocks to design a trading strategy. It generates the QuantConnect LEAN algorithm in Python and backtests it on historical data, across 26 guided levels.

The highest peak is the one to distrust. The optimiser flags results that are likely luck.

A parameter optimiser with 27 metrics and 164 quantities mapped to LEAN, in Python with a web UI in a native window, .NET 10 and pythonnet. Results are shown as they are, losses included.

C++17 · Monte Carlo · Python via ctypes

An option pricing engine in C++

European, American and Asian options priced three ways in C++17: Black-Scholes with Greeks, a 2,000-step binomial tree, and a multithreaded Monte Carlo with antithetic variates, called from Python through ctypes.

161Mpaths a second
8threads, verified under ThreadSanitizer
2.3×vectorised NumPy

Antithetic variates: every random draw is used twice, once mirrored, so the noise cancels faster at no extra cost.

The panel beside runs a small JavaScript version of the Monte Carlo in your browser, against the Black-Scholes price. Change the volatility or the strike and watch the estimate settle.

Machine learning · SQL · fairness

Credit default risk model

Credit features in SQL over 30,000 card holders, gradient boosting against a logistic-regression baseline, scored once on 6,000 held-out clients: AUC 0.78 against 0.73.

Reviewing the riskiest fifth catches 51% of defaulters against 48% for the baseline; sex, marital status and age are kept out of the model and used only to test fairness.

Code NLP · DistilBERT

Financial news sentiment

DistilBERT fine-tuned on 4,836 annotated sentences, near-duplicates kept on one side of the split: 86% accurate against 76% for TF-IDF, and 98% where every annotator agreed.

Macro-F1 0.85 over three seeds; 93% of the errors are on sentences the annotators themselves split over.

Code Risk · GARCH · backtesting

Value-at-Risk and Expected Shortfall, twenty years

Five models on twenty years of FTSE 100 and S&P 500 returns, judged from 2007 over 4,979 trading days, every forecast using only the data available that evening.

GARCH-t breaches least, 1.5% against a 1% target, and Kupiec rejects all five: that is what is reported, not the flattering one.

Code Portfolios · walk-forward

ETF momentum and portfolio construction

Six strategies over ten asset-class ETFs across 233 months, walk-forward and net of 5 basis points on every unit traded.

None beats equal weighting with statistical confidence. In 2008 momentum fell 7% against 18% for 60/40, while minimum variance gained 2%.
